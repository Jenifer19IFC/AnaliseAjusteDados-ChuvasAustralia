# Australia Rainfall Data Analysis

An exploratory data analysis (EDA) project developed in Python using approximately 10 years of Australian weather observations. The project focuses on data cleaning, transformation, statistical analysis and visualization to identify patterns related to rainfall occurrence.

> **Academic Project** — Data Analysis

---

## 🚀 Features

- Data cleaning and preprocessing
- Missing value treatment
- Duplicate detection
- Outlier identification
- Feature transformation
- Exploratory Data Analysis (EDA)
- Correlation analysis
- Statistical analysis
- Interactive and static visualizations
- Business insights based on historical weather data

---

## 📊 Dataset

- **Source:** Kaggle – Weather Dataset (Australia)
- **Records:** ~145,000 daily observations
- **Period:** 2007–2017
- **Variables:** 23 weather attributes

The dataset contains daily meteorological observations from multiple Australian weather stations, including temperature, humidity, wind conditions, atmospheric pressure and rainfall.
